# Contributing to this project

Thank you for your interest in contributing. This document describes how to report issues and how
to contribute code or documentation.

## Reporting issues

If you find a bug or have a question about the content of this repository, please
[create an issue](https://github.com/SAP-samples/explaining-sparse-autoencoder-latents-with-domain-adapted-llms/issues).
When reporting a bug, please include:

- A clear description of the problem and the expected behavior.
- Steps to reproduce it (commands, configuration, environment).
- Relevant logs or error messages.

## Contributing code

1. Fork the repository and create your branch from `main`.
2. Make your change, keeping it focused and consistent with the surrounding code.
3. Ensure the project still runs and any relevant scripts/tests pass.
4. Open a pull request against `main` with a clear description of what you changed and why.

Pull requests are reviewed before merging. Changes to `main` must go through a reviewed pull
request.

## Developer Certificate of Origin (DCO)

Due to legal reasons, contributors will be asked to accept a Developer Certificate of Origin (DCO)
when they create their first pull request to this project. This happens in an automated fashion
during the submission process. SAP uses
[the standard DCO text of the Linux Foundation](https://developercertificate.org/).

## Code of Conduct

All members of the project community must abide by the
[SAP Open Source Code of Conduct](https://github.com/SAP-samples/.github/blob/main/CODE_OF_CONDUCT.md).
Only by respecting each other can we develop a productive, collaborative community. Please report
any unacceptable behavior or violations of this code of conduct to a project maintainer.
